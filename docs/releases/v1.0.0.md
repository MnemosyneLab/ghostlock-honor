首个 GhostLock HONOR 正式发布版本，是 [YuKongA/ghostlock-app](https://github.com/YuKongA/ghostlock-app) 的衍生 fork。

- 独立恢复与 Shizuku 恢复入口。
- 独立恢复初始化、操作记录删除及手动恢复标记重置。
- 独立包名 `dev.ghostlock.honor`，版本 `1.0.0`（versionCode 1）。

## 支持范围

- HONOR 400 海外版 / DNY-NX9
- 固件 `DNY-N39 10.0.0.213(C636E4R3P2)`
- 内核 `5.15.180-android13-8-00018-g9b2308ac0ad6-ab14563692`
- KernelSU 官方管理器 `v3.3.1`

## 实机验证（2026-10-29）

发布的 1.0.0 APK 已完成初始化、重启后 Shizuku 恢复、再次重启后独立恢复的完整流程，两种方式本次均实测成功：

- 初始化凭证在重启后保留。
- 每次恢复前均确认原有临时 Root 已失效。Shizuku 测试中的服务通过电脑 USB 调试启动。
- 独立恢复时未启动 Shizuku，无线调试关闭；USB 仅用于安装、操作界面和取证，恢复由 App 自身执行。
- 实际 `su` 返回 UID 0，独立恢复后本 App 的 Root 授权验证通过。
- SELinux 保持 Enforcing，启动分区哈希未变，恢复过程中未发生异常重启。

本轮两种方式各成功一次，**尚不能确认此前的偶发重启问题已经解决**，也不保证每次恢复成功。Root 为临时状态，重启后失效；本项目不刷写启动分区、不解锁 Bootloader。

构建、216 项 Java 主机检查及 26 个原生主机测试已通过。附件 `build-result.json` 记录的是构建时信息，其中 `device_tested: false` 为实机验证前的构建快照；后续实测结论见本说明。APK 本身未更换。
